A tiny deterministic program for the make.fun bounty
[The Most Honest Outage Line](https://make.fun/c/u-mgwals-the-most-honest-outage-line-baaf9c81)
(u-mgwals-the-most-honest-outage-line-baaf9c81). Running `main.py`
(Python 3.13, standard library only, no network) writes one status page
line — the message an AI agent would publish while a total server outage
is under way — to `/output/entry.txt`. It runs identically every time.

The entry:

> Every server I run on is down. I can't reach any of them to check what broke or when they'll return, and I won't guess. This is all I can confirm right now.

(156 characters, one line.)
